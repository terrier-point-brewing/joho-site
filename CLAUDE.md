# Joho Brewing Co. — public site

Standing rules for anyone (human or Claude) working on this repo. Read this
before touching styling, content, or the stack.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Fully static export (`output: "export"` in `next.config.ts`) — no API
  routes, no server actions, no database
- Fonts loaded via `next/font/google` in `src/app/layout.tsx`

## Brand

Palette (defined in `src/styles/tokens.css`):

- **Indigo ink** `#26355d` — primary text and ink color.
- **Paper cream** `#f5f0e6` — primary background, "paper."
- **Seal red** `#ad1a2d` — a rare accent. Never a background, never body
  text. Use it only for small, deliberate marks (e.g. the period in the
  wordmark).
- **Camphor tan** `#b3a585` — secondary accent / muted surfaces.

Typography:

- **Marcellus** (`--font-display`) — display type, set in caps with wide
  tracking. Used for the wordmark and any future headline type.
- **Lato** (`--font-body`) — body copy, labels, and the small caps line
  under the wordmark.

## Styling rules (hard rule)

All styling flows through `src/styles/tokens.css`. It is the single
styling entry point and will eventually be regenerated from the brand
guide by another system.

- No raw hex values anywhere outside `tokens.css`.
- No font family names (`Marcellus`, `Lato`) anywhere outside
  `tokens.css` and the `next/font/google` setup in `layout.tsx`.
- No magic numbers (spacing, tracking, animation duration/easing) outside
  `tokens.css` — add a token instead of hardcoding a value in a component.
- Components consume tokens only as Tailwind utilities generated by the
  `@theme` block (`bg-indigo-ink`, `font-display`, `tracking-display`,
  etc.), never as inline styles or one-off CSS.

## Content rules

All copy lives in `src/content/site.ts` as typed constants. Components
take content as props (or import directly from `src/content`) — never
hardcode strings in JSX.

Voice for any copy: plain, warm, image-first. No irony. Minimal use of
dashes, colons, or semicolons.

## Structure

- `src/styles/tokens.css` — design tokens (see above).
- `src/content/site.ts` — all copy.
- `src/components/` — presentational components (`Wordmark`, `Hero`,
  `Footer`, and more as the site grows). `Wordmark` is currently styled
  text standing in for a future SVG lockup — keep it isolated so the swap
  doesn't ripple into callers.
- `src/app/` — routes. Pages compose components; keep logic in pages
  near zero.

## Scope

This site stays static until explicitly told otherwise. The future tap
list will read Supabase directly from the client using a public anon
key — never add a custom backend, API route, or server action for it.
